Aturan Process & Import

1 Pengolahan Data Sales
  • Konversi ID ke Number & tanggal ke yyyy-mm-dd.
  • Pecah SATUAN/ISI menjadi SATU, AN/, ISI.
  • HARGA PCS = JMLBRUTTO / QUANTITY.
  • HARGA CTN = HARGA PCS × AN/.
2 Mapping Template Import
  • salesmanID ← SLSNO; salesorderNumber ← NO.FAKTUR.
  • salesorderDate ← TGLFAKTUR; invoiceDate ← TGL PENGANTARAN.
  • invoiceNumber = I + salesorderNumber.
  • 3 customer ID ← OUTLET; productCode ← PCODE; qtySold ← QUANTITY.
  • sellingPrice ← HARGA CTN (2 desimal).
  • Disc1 ← PROMO UANG; Disc2 ← RP.DISC2; Disc3 ← RP.DISCPC; Disc4 ← RP.DISC1; Disc5 ← DISCOUNT.
  • Disc nominal non-zero < 100 dikonversi otomatis: (disc / sellingPrice) × 100 (2 desimal tanpa %).
