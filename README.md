# Nabati Converter

Aplikasi Web Konverter Data Penjualan Sales Import untuk Nabati.

## 🚀 Fitur Utama
- **Konversi Otomatis**: Mendeteksi format file *Sebelum di Olah* dan *Sesudah di Olah*.
- **Multi-Format Export**: Export ke Excel Hasil Olah (`.xlsx`), Excel Ready-Import (`.xlsx`), CSV (`.csv`), dan TXT (`.txt`).
- **Demo Data Generator**: Tombol simulasi pengolahan data bawaan tanpa perlu upload file.
- **Support Branch**: Mendukung Branch Air Molek (`1764907397498`) & Ujung Batu (`1764907108089`).
- **Offline Browser**: 100% diproses di browser lokal tanpa mengirim data ke server mana pun.
